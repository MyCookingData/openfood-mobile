# **App Name**: TiKwenEats

## Core Features:

- Responsive Main Navigation: Implement a dynamic navigation system with primary links (Home, Search, Orders, Profile), adapting from a top navigation bar on desktop to a bottom navigation bar or hamburger menu on smaller mobile screens.
- Location-Based Filtering: A prominent header component that allows users to select their commune within the specified Nord Caraïbe zone, enabling location-specific filtering of available restaurants and offers.
- Local Partner Restaurant Display: A visually engaging section showcasing partner restaurants through interactive card components, featuring restaurant name, designated zone, and a 'Local Partner' badge. This feature will initially use hardcoded placeholder data for 'Open Food (Case-Pilote)', 'Remy Pizza', and 'Kay Dada'.
- Reusable Restaurant Card Component: Develop a dedicated and reusable UI component ('RestaurantCard') designed to present each restaurant's key information in a clear, consistent, and appealing card format.
- AI-Powered Local Food Insights: Leverage a generative AI tool to provide unique insights, engaging descriptions, or interesting facts about Martiniquan dishes and local ingredients relevant to the user's selected region, enhancing the food discovery experience.

## Style Guidelines:

- The primary interactive and brand color is a vibrant Coral Red (#FF5A5F), embodying energy and local flavor. HSL(358, 100%, 67%).
- A clean, nearly-white background color (#F2F1F1) derived from the primary hue but highly desaturated, providing a light and airy canvas for content. HSL(358, 20%, 95%).
- An accent color of bright Orange (#F2660C) will be used for calls-to-action and key highlights, providing a warm, complementary contrast to the primary color. HSL(28, 90%, 50%).
- The primary typeface for both headlines and body text is 'Inter', a modern sans-serif chosen for its excellent legibility, clean lines, and neutral yet contemporary aesthetic, aligning with the clean and modern design request.
- Utilize a consistent set of modern, rounded icons (e.g., Material Symbols or an equivalent web-friendly library) that align with Material Design 3 principles and support clear communication throughout the user interface.
- The layout embraces a 'mobile-first' and 'responsive' philosophy, ensuring a seamless experience across all devices. Content will be organized using card-based structures for restaurants, with generous rounded corners (16px) for a soft and approachable feel.
- Incorporate subtle, context-aware animations for user interactions (e.g., button hovers, card selections, navigation transitions) to enhance usability and provide gentle visual feedback without distracting from the core experience.
