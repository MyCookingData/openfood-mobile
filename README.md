# 📱 OpenFood Mobile — Application Client & Livreur

Application mobile Flutter (iOS, Android, Web) pour la plateforme OpenFood en Martinique 🇲🇶 et dans les Caraïbes.

## 🌟 Fonctionnalités Clés
- **Parcours Client :** Recherche de restaurants, navigation dans les cartes/menus, options & suppléments personnalisés, panier en direct, calcul des frais kilométriques, application de codes promos, paiement sécurisé par CB (Stripe).
- **Parcours Livreur :** Tableau de bord de livraison, carte interactive (`flutter_map` + OpenStreetMap), géolocalisation en temps réel, acceptation des courses et suivi du statut.
- **Paiements Sécurisés :** Intégration Stripe avec autorisation préalable et capture manuelle à l'acceptation par le restaurateur.

## 🚀 Installation & Lancement
```bash
flutter pub get
flutter run
```
